The World in One Day — Monday 23 November 2026. A newspaper front page that sums up the day's world news in a single image: COP31 climate talks collapse in Antalya, a Russian drone leaves 14 missing near Kyiv, a Russian cargo ship burns off Finland, a factory fire in Indonesia, South Korea's education minister resigns over an AI exam-cheating scandal, Nepal's PM meets Modi, and India post a record 720 in Wellington — plus briefs from Mexico, US tech and the UN court.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only, no network) copies `entry.png` — the front page rendered from `index.html` — to `$MAKEFUN_OUTPUT_DIR/entry.png`. Running it twice writes byte-identical output.
